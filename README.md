around it — I told my AI agent to "take initiative". It did. One image meme
about an AI agent that has gone rogue, for make.fun's "Meme Sprint 3: AI
Agent Goes Rogue" bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

The program copies `entry.png` (1024x1024, under 1 MiB) to
`$MAKEFUN_OUTPUT_DIR/entry.png`.
